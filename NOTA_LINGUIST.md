# GitHub Linguist en este repositorio

Las variantes de este ejercicio utilizan principalmente C y una variante usa
tambien Assembly RISC-V para evaluar guardas de transicion.

Por tanto GitHub puede mostrar:

```text
C          xx.x %
Assembly   yy.y %
```

Los porcentajes exactos dependen del codigo real.

PowerShell, CMake, JSON, configuracion de VS Code y Markdown no deben alterar la
barra de lenguajes.
