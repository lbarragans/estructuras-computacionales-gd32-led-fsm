# Regla global de lenguajes

La barra **Languages** de GitHub debe representar los lenguajes que realmente
forman parte de las soluciones educativas.

## Regla

- C cuenta cuando existe implementacion real en C.
- Assembly cuenta cuando existe implementacion real en RISC-V Assembly.
- FreeRTOS es una tecnologia/RTOS, no un lenguaje.
- PowerShell, CMake, JSON, VS Code y Markdown son herramientas o documentacion.
- No se oculta C para fabricar Assembly 100%.
- No se oculta Assembly para fabricar C 100%.
- Un 100% solo es correcto cuando la solucion detectable utiliza de verdad un
  unico lenguaje.
